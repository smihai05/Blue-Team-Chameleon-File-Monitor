# Blue-Team-Chameleon-File-Monitor
A python app that keep tracks of the files you have on your pc after the first scan that you gave her, it let's you see modified files, changed ones and new ones


To run it run this command in the terminal:

py -m PyInstaller --clean --onefile --windowed --noconsole --add-data "chameleon.ico;." --icon="chameleon.ico" chameleon.py
